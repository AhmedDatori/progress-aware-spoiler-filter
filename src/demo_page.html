The comment thread

Each show has 50 comments picked at random from the hand-labelled test set (36 about the story, 14 not). "Spoiler for you" uses the real label: the comment is about the story and about a later episode than yours. Our filter hides a comment when P(about the story) × P(about a later episode) is above 50%; the normal detector hides every comment it thinks is about the story. Code and details on GitHub.
